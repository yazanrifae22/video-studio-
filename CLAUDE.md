# Clips Viral Studio

Multi-brand short-form studio (rankings · long-form clipping · compilations · Arabic quiz). Videos are built as plain timelines (`timeline.json`) and rendered with ffmpeg (`packages/render`); OpenChatCut was retired 2026-11-02.
The main Claude session is the **orchestrator**; 10 subagents live in `.claude/agents/` and follow `AGENTS.md`.

## Resume a session
1. `docs/STATUS.md` — current phase, blockers, next executable task (update it at the end of every session).
2. `npm run -s cli -- status` — productions, jobs, rights, agents, recent events.
3. `memory/` — curated decisions and lessons. Research: `research/tools/*.md`, `research/market/`.
4. `docs/north-star.md` (the ONE goal: every video built for 1M+ views, honestly; kids via parent-trusted quality) and `docs/viral-radar.md` (daily "what is viral now → script idea" loop, records in `research/radar/`).

## Rendering (packages/render, since 2026-11-02)
- Build = `npm run -s cli -- build <id> --agent <a>` (quiz: `quiz:build <id>`): the builder records its edit into `productions/<id>/vN/timeline.json` (quiz: `render.timeline.json`) → `packages/render` renders it with ffmpeg (chunked h264_nvenc, text cards via one headless Chrome page) → `render.raw.mp4` → `master()` (−14 LUFS, ≤ −1.6 dBTP) → `render.mp4` → techqa.
- Re-render a hand-edited timeline without rebuilding: `npm run -s cli -- render:timeline <timeline.json> <out.mp4>` (raw, unmastered; master it with `master()` from packages/occ/src/build.ts, or rebuild).
- Timeline format and semantics: `packages/render/src/timeline.ts` (video tracks paint bottom→top, contain-fit + transform in % of canvas, item-local keyframes with CSS easings, fades, backgroundFill, text props). Smoke test: `scripts/test-render.ts`.
- Captions = text items built from our word timestamps (Arabic quiz captions are our own RTL HyperFrames layer).
- quiz-ar LONG-FORM (2026-11-12, series «تعلّم بالأسئلة», 16:9, 8-12 min): `quizlong:plan <id>` / `quizlong:build <id>` (packages/quizlong; `episode.json` -> `show.json` -> template `packages/quizlong/template` captured by 4 Chrome workers -> stems -> timeline -> master -> techqa; no burned captions, `captions.srt` + `chapters.txt` per version). Categories since schema 1.4 (2026-11-13): flags (`clue.type "flag"`) and animals (`clue.type "animal"` = a Noto Color Emoji glyph with zoom / blur / strips / silhouette, palette `"wild"`). Episode shape, rules, categories and plan: `docs/brands/quiz-ar/longform-series.md`; every fact needs a source URL and an independent fact-check before `script:approve`. Own agents (2026-11-13): `showrunner-shu-shayef-long` (stages W/B/K), `quiz-fact-checker`, `quiz-picture-judge` (every picture item, before the first voiced build), `blind-viewer-nada`, `blind-viewer-abukarim`; loop in the series doc, section "Team and loop". Upload = `scripts/youtube-long.ts upload|record <pid>` (private + thumbnail + playlist + captions; end screen, visibility, pinned comment in Studio); the daily uploader never plans long-form.
- Parity with the old OpenChatCut renders proven 2026-11-02 (SSIM ≈ 0.99, identical raw LUFS/TP) on rankings, quiz, Mission Voices inserts, TWIWM push/pull motion and fades. Older versions may still carry `render.occ.mp4`, `occ-pool.json`, `occ.json`, `openchatcut_project_id` (history only; nothing reads or writes them now).

## Token budget (owner, 2026-10-22: "agents are draining tokens")
- Fresh, short-lived agents per task with a tight brief; never resume a huge-context agent for a small fix (resume cost = its whole context). Retire agents when their task ends.
- Default models: showrunners/QA/rights = sonnet; opus only for pipeline engineering or hard judgement.
- QA: run the automatic checks first (techqa, captions_audit, peek-proof); look at ≤12 small frames (scale ≤360 px) aimed at the specific rounds; no full contact-sheet re-reads on re-QA — verify only the listed defects + a regression diff.
- Rights: countersign art/voice once when new; per-render checks = sha/copy lint, not a full re-view, unless assets changed.
- Batch fixes: collect all pipeline items into one engineer change, one rebuild per video per QA round. Max ~3 agents running at once.
- Orchestrator: short status messages; no re-reading large files; relay findings as compact lists.

## Lessons that cost rounds (don't repeat)
- Rights-scout overturns are common: network TV inside NASA compilations (CBS), CSU/CIRA loops (no licence), contractor or co-produced reels (USIA+private), citizen-processed JunoCam (Eichstädt), Commons PD tags on non-NASA producers. Check primary pages, not Commons tags.
- Answer leaks hide in layers: sequence answer digit showed through the «؟» (aecz approved then withdrawn, 3uyp). Before approving, check a question-phase frame of every round for answer colour; techqa leak guard added.
- Quiz fairness must be proven, not asserted: a "peek" clue (corner of a 7) was shared by 1/4/5 in the same font → blocker. Test every partial clue against all options at 360 px width; one digit system per video; no "حدس"/intuition claims (brand = observation).
- Generated product art can still hit trade dress (quiz-ar sneakers = Chuck Taylor lookalike, rejected); prompt away from iconic silhouettes and get rights-scout eyes on every generated product image.
- Labels must match the picture: CGI ≠ footage, generic launch ≠ a named mission, planet-wide wind ≠ a storm's wind, title claims must survive "what about X?" (Uranus beat 3 of 5 entries).
- When ASR and NASA's own caption file disagree on a word, follow NASA's record (the "wow"/"well" round trip).
- Text-led videos (no TTS) cap originality/format ≈7–8; narration is the next quality lever.
- Shared `build.ts` is edited by showrunners too: re-run `npm run -s typecheck` + `scripts/test-build-helpers.ts` + `scripts/test-tone-bed.ts` after any builder change; a mid-edit file once broke a build (DC offset).
- Agents on this Windows box: use `python` (or .venv-asr), never `python3` — it is the Store stub and hangs a shell for an hour (QA group G, 2026-10-23).
- `.venv-asr` needs `av==13.1.0` (av 19 breaks faster-whisper 1.2.1 `decode_audio`: "unexpected keyword metadata_errors"; QA lost ASR checks for a day, 2026-10-28). Reinstall with `uv pip install --python .venv-asr/Scripts/python.exe --only-binary :all: av==13.1.0` (the venv has no pip).
