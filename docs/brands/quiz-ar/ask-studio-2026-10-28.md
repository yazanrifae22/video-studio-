## 1) Why not viral / blockers to 1M
- [Ask Studio] 1M-view quiz Shorts typically show viewed-vs-swiped 80%+ and APV 110-130%+ (rewatches/loops). Channel ceiling: 71.9% viewed, 81.8% APV; weak ones <50% viewed, 55% APV.
- [Ask Studio] Hook: first 1-2 s are calm/static (3 static cherries + "أي كرزة حمرا؟"; "التفاحة ورا أي خنزير؟ تابعها"); chick video opens with a counting pattern then switches to tracking. >50% swipe on the weak ones.
- [Ask Studio] Outro cliff: retention holds 72-85% through the rounds, then collapses in the last 5-9 s (cherry 71% -> 37.5% from 0:33; pig 52% -> <7% from 0:31) exactly when the voice says "كم جواب صح جبت من أربعة... اكتب نتيجتك بالتعليقات".
- [Ask Studio] Length 35-41 s is too long; target 20-25 s.
- [Ask Studio] Mixed "4-in-1" format (shuffle + math + spot-diff + memory) = "cognitive whiplash", re-learning a game every ~7 s.
- [Ask Studio] Catalog titles ("٤ جولات، كم جبت؟") look like an archive; no curiosity gap.
- [Ask Studio] Predictable equal rounds; no rewatch/pause trigger (too easy).
- [Ask Studio] Batch/irregular posting.

## 2) Hook & timing
- [Ask Studio] 0-0.8 s: immediate motion (shuffle, vanishing, countdown bar) + tick/whoosh + command word ("ركّز!", "تحداك!", "اختبار نظر!").
- [Ask Studio] 0.8-2 s: highlight the target, big high-contrast text in the top third, stakes line ("لا تشيل عينك!").
- [Ask Studio] 2-3 s: round 1 already running with a visible timer; zero dead pauses; first spoken syllable = first on-screen word on frame 1.
- [Ask Studio] Patterns: (A) ego/IQ ("اختبار تركيز: ٩٠٪ بيغلطوا من أول جولة"), (B) sensory command ("لا ترمش!"), (C) fast countdown ("عندك ثانيتين بس!"). Avoid listing objects before starting ("حليب، عنب، وبرتقال...").
- [Ask Studio] Swipe decision happens at ~0.8-1.5 s.

## 3) Channel advice
- [Ask Studio] Length 20-25 s, 3 rounds, one mechanic per Short escalating in speed (R1 easy confidence, R2 fast, R3 hyper-speed/trick).
- [Ask Studio] Cut the outro: end when the last answer lands, or loop the reveal back into frame 1. Reveal pauses 3-5 s -> ~1.5 s with a sound cue.
- [Ask Studio] Post 17:00-20:00 Cairo/Riyadh (secondary 21:00-23:00); Thu/Fri evenings strongest. 1 Short/day (or 5/week), no same-hour batching.
- [Ask Studio] Audience (share of views / APV): Egypt 45.9% / 66.5%, Saudi 13.7% / 80.2%, Syria 7.8% / 76.4%, Algeria 6.3% / 72.8%, Iraq 4.2% / 75.5%, Morocco 3.8% / 76.7%, Jordan 3.3% / 79.3%. Saudi + Jordan watch longest. [not independently verified in Analytics]
- [Ask Studio] Animals/vibrant food beat inanimate objects.
- [Ask Studio] Signal the memorise goal before a memory flash ("احفظ أماكنهم... عندك ثانيتين!") so it does not feel unfair.

NOTE: those example videos (pear, windmills, frogs, buses) are SCHEDULED for 15-18 Nov, not published, so titles can still be changed before they go live.
- [Ask Studio] Descriptions: one-line challenge + "اكتب نتيجتك من ٤" + 3 hashtags (#ألغاز #اختبار_ذكاء #shorts).
- [Ask Studio] Pinned comment on top/recent videos: score/debate bait ("كم جولة جبت صح من ٤؟ مين غلط بالجولة الثالثة؟", "مين قدر يحلها بدون ما يوقّف الفيديو؟").
- [Ask Studio] Playlists: "تحديات اختبار النظر والتركيز" (shuffle/tracking, best first), "ألغاز وسرعة بديهة" (spot-diff + memory), "أصعب التحديات" (fastest/trickiest).

## 5) Ideas (Ask Studio)
- Viewer comments ask for harder ("ياخي انا تعبت من الأشياء السهلة جيب اصعب", "اريد اشياء اصعب", "المرة المليون الي اجيب بها ٤من٤"); ~90% of comments are people posting their score.
1. Fast 3-level cup shuffle with lively pets (cats/puppies/bunnies), speed escalating, last round hard (very likely).
2. Standalone 10-20 s spot-the-difference / odd-one-out with countdown timer (very likely; retention spike on the diff round).
3. Speed memory swap: show 4 colourful treats 2 s, flash, swap two, name the swap (somewhat likely).
