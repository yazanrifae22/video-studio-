# Podium Pop: 504 TOP 5 categories to hunt clips for

Every category below is one ready-to-make video. Your download tool fills its folder, and the studio builds the TOP 5 from it.

## Where to put the clips

1. **One folder per category.** Each category lists its own folder under `E:\clips-viral\data\media\owner-supplied\micro\`. Example: Messi nutmegs go in `E:\clips-viral\data\media\owner-supplied\micro\MC-001-messi-nutmeg\`. Create the folder if it doesn't exist; copy the path exactly so the studio finds it.
2. **How many clips.** Aim for **8-12 clips** per category. Some get rejected, and the video needs **5 clean ones**.
3. **File names.** Keep your tool's names (for example `messi-nutmeg_01.mp4`). Use `.mp4` only, and put no sub-folders inside a category folder.
4. **What gets rejected.** Burned-in watermarks, TikTok/IG handles, subtitles, reaction split-screens, news banners, compilations with their own text, and clips where the subject leaves the frame at the payoff. Vertical or close shots work best.
5. **Tell me when it's ready.** Message the ID, for example `MC-001 ready`. The studio checks each clip once (the result is saved next to the clip as `<clip>.analysis.json`, so no clip is checked twice), picks the best 5, and builds the video.
6. **Tick it off.** Change `[ ]` to `[x]` on a category once its clips are in the folder, so this file is also your checklist.

**Key:** viral ★ = how likely it is to pull views (5 = highest). Difficulty = how hard it is to find 5 clean clips (easy / medium / hard). Both are estimates.
