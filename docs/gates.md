**quiz-ar puzzle-judge** (owner 2026-11-08, quiz-ar only): `.claude/agents/puzzle-judge.md` stage P `productions/<id>/puzzle-judge.json` (after puzzle art + quiz.json, before the script round) and stage V `v<N>/qa/puzzle-judge.json` (video round, next to qa-director); pass = no wrong/ambiguous/leaking round, no difficulty ≤ 3, no broken visual, and mean enjoyable ≥ `puzzle_enjoy` (7); schema in `validate-review.py` (puzzle-judge). Stage P records `input_sha256` = `npm run -s cli -- review:hash <id>` `puzzle_sha256` (quiz.json rounds without wording + art/ and referenced files); **stage V runs only when that hash changed or qa-director flags a puzzle defect** (audit #2 F6b); approve (story.json) enforces it (row 6).

**Podium Pop clip-hunter + cut-judge** (2026-11-08, viral-rankings only): `clip-hunter` writes `productions/<id>/hunt.json` (TikTok-only Video Hunter hunts, picks registered with `library:register`); `cut-judge` stage C `productions/<id>/cut-review.json` (after moments + draft plan, before hook-architect) and stage V `v<N>/qa/cut-review.json` (video round, next to qa-director). Pass = every entry score ≥ `cut_entry_min` (8) AND `number1_strongest` AND no payoff cut off; schemas in `validate-review.py` (hunt, cut-review). Stage C records `input_sha256` = `review:hash` `cut_sha256` (ranking-plan.json entries: source, in/out, payoff, framing, extra shots, order); **stage V runs only when that hash changed or qa-director flags a cut defect** (audit #2 F6b); approve (story.json) enforces it (row 6); qa-director cites a failing stage V as a blocker.

**Score normaliser** (one rule everywhere, `numScore` / `forecastOf` / `scoreOf` / `viewerScoreOf` in gates.ts; the dashboard `apps/api/src/workflow.ts` imports them): a score may be a number, a numeric string or an object `{score}` / `{viewer_score}`; script-doctor `forecast` may be a number or `{score, ...}` (falls back to `forecast_detail.score`); round = `round` or `pass_n`.

**Script files hashed per brand** (`SCRIPT_FILES` in gates.ts; `?` = optional, hashed when present): quiz-ar `quiz.json`; kids `episode.json` + `script.json?`; tech/celebrity `script.json` + `spec.json?`; everything else `script.json`. Any edit after approval (or an optional file appearing) = hash mismatch → full script round + `script:approve`, or inside a video round `--delta` (2b).

**Files written by the gates**
- `script-approval.json` (only `script:approve`): on success `{approved:true, round, forecast, script_sha256, script_files, checks, round_status, history, deltas?, at}`; on refusal `approved:false` + `failures` + `gap_to_gate` (so builders still refuse). `history` keeps one entry per full round; `deltas[]` one entry per `--delta` call `{at, changed_files, changed_lines, sensitive[], viewers_rerun, doctor_file, approved}`.
- `approved-script/` (copy of the script files + `meta.json`) at every approval: the base a delta diffs against.
- `script-doctor.history.json` — **append-only** `{rounds:[{round, forecast, verdict, file_mtime, recorded_at}]}`, one entry per distinct script-doctor run, appended by `script:approve` and `script:round-check` (never edit it). Round history = this file + `script-doctor.r<N>.json` copies + the current `script-doctor.json` + `script-approval.json` history (latest record per round wins). script-doctor may keep overwriting `script-doctor.json`; run `script:round-check <id>` after each doctor round so the round is recorded.
- `vN/build-reason.json` `{version, command, reason, rebuild, last_qa_version, builds_since_qa, agent, at}`.

**fix-ledger.json** (I6; showrunner fills, script-doctor verifies): `{items:[{source:"fresh-eyes"|"panel"|"script-doctor", item:"<gap_to_gate item text, copied>", applied:true | rejected_reason:"why", round?, by?, note?}]}`. Matching = same source + same item text (case/space-insensitive). Every item of a weak fresh-eyes S / panel S with ≥ 2 swipes before the payoff needs `applied:true` or a `rejected_reason`.

**Delta "hook/payoff/ending line"** = a changed leaf whose key path or line label (`id`, `line_id`, `role`, `kind`, `type`, `beat`, `job`, `name`, `section`) matches hook|payoff|ending|outro|reveal|punch|final|closing|loop|first_line|signature|cta|answer, or the first/last item of a `lines`/`beats`/`narration`/`scenes`/`segments`/`rounds` array (`scriptDiff` in gates.ts).

**Validation** (I9): `python scripts/validate-review.py [--json] <file>...` checks script-doctor / fresh-eyes / panel / packaging / viral / QA review / fix-ledger shapes from CONTRACT.md (type from the file name or `--type`); exit 1 on a malformed file. Reviewers run it before finishing; `script:approve` and approve run it and refuse with the error. A reviewer-written `gate` that differs from config/gates.json is only a warning (config wins).

**Render viral vs forecast** (I8): qa-director writes `forecast_delta` = render viral score − script forecast into `vN/qa/viral.json` (`scripts/qa-pack.py` puts `script_forecast` in `qa/pack.json`; the gate computes it when missing). `/api/productions/:id/progress` shows `forecast_delta`, `viral_mode` and **"SHELVE SUGGESTED"** (`shelve_suggested:true`) when video round ≥ 2 and viral < shelve_viral_round2 — an orchestrator rule (keep with ONE batched fix, or shelve); approve does not refuse on it. **PAUSED until 2026-11-22** (`shelve_viral_round2_paused_until`; `shelveActive()` in gates.ts): progress never suggests it while paused and returns `shelve_paused_until`.

**Publishing** (I1): `scripts/publish-plan.py` and `scripts/fb-plan.py` take title/description/hashtags from `packaging.json` (`chosen_title`, `description`, `hashtags`; empty or "KEEP …" description = script.json's), falling back to script.json; credits (`attribution_block`) stay from script.json. Only new plan entries: scheduled/published videos are never regenerated. `scripts/youtube.ts upload` refuses an entry whose title ≠ packaging `chosen_title` (stale plan → re-run publish-plan.py) and sends plan `tags`.

**Draft modes** (`--no-tts`, `--plan`) spend nothing and stay allowed without approval; their output (`draft/` or the new `vN/`) gets `UNAPPROVED-DRAFT.json` and cannot pass stage qa. `build` (clipping/rankings/compilations) has no draft mode: `--no-render` still voices, so it is gated.

**Refusals** print every failure, the next required reviewer (`next:`), and each reviewer's `gap_to_gate` items (`item now->needed: fix (+points) [owner]`); the approve endpoint returns them as `issues` and `gap_to_gate`.

**Text safety** (owner 2026-11-08: "every text in the frame viewable: not overflowing the video or cut"). Code: `packages/render/src/text-safety.ts`; config `config/text-safety.json`; tests `scripts/test-text-safety.ts`.
- Every build (`renderTimeline` with work dir `productions/<id>/vN/render-work`) writes `vN/qa/text-safety.json` `{items:[{id, source timeline|html|layer, layer, t_start, t_end, text, box{x,y,w,h,pct}, cap_px, issues[], details[], exempt[], blocking}], counts, blocking, pass, unmeasured[]}`. Re-measure an existing render without re-rendering video: `npm run -s cli -- text-safety <id> [--version N]` (exit 1 when failing).
- Measured in Chrome after fonts load: timeline text items (the text-card page: ink box / pill box after the fit loop, word spill, cap height, RTL order probe); HyperFrames layers baked into video items (quiz-ar rounds + Arabic captions, tech/celebrity scenes: the project `index.html` in the render tmp is seeked every 0.1 s and every visible text block measured, incl. parent `overflow` clipping and CSS transforms); text-bearing image/alpha-video overlays (title band, rail, badge, kids wall: painted alpha box, warnings only).
- Issues: `clipped` (word wider than its box, cut by a parent box ≥ 0.3 s, or cut by the canvas), `offcanvas`, `unsafe_margin` (4 % of the short side), `ui_zone` (9:16: bottom 20 %, right 15 %, top 7 %; 16:9: bottom 10 % player controls; brand zones from the brand docs replace the defaults: Podium Pop BRAND-GUIDE §8, quiz-ar visual-system.md), `too_small` (cap height < 2.2 % of the canvas height for role `main`; role `label` 1.4 %: quiz round counters, Podium Pop rank-rail sublabels/badges/chips; role from the builder: timeline text `role`, HyperFrames `data-ts-role`, else a brand `roles` rule), `overlap` (two texts sharing ≥ 10 % of the smaller box for ≥ 0.3 s), `rtl` (Arabic punctuation/number on the wrong end, pre-shaped forms). Exemptions are explicit per brand in the config (e.g. Podium Pop title band / rail).
- Blocking: clipped, offcanvas, overlap, too_small, and ui_zone / unsafe_margin unless exempted; `rtl` and painted-layer findings warn. prelint fails on blocking items (and refreshes a missing/stale report); `production:stage <id> qa` refuses a failing report (`--force --note`).
- Video round: **frame-text-inspector** (haiku) reads the report + ≤ 16 frames at 360 px (first/last moment of each text) and writes `vN/qa/text-check.json` `{pass, frames_checked, issues[{t, text, problem, fix, owner, blocker}], gap_to_gate[]}` (`validate-review.py` type `text-check`); approve (new loop) needs `pass:true` (override `force_note`).
